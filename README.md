## CONTENIDO

### 1. Fecha.java
En una institucion bancaria se requiere hacer cierto manejo de fechas para determinar, por ejemplo, 
la fecha final de una inversion de dinero. Por ello el proposito de este problema es escribir una clase para crear y manejar fechas.
